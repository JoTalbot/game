# Политика конфиденциальности — ИГРА

ИГРА хранит прогресс **на устройстве**: в Android — в `SharedPreferences`
через нативный мост приложения, в браузере — в `localStorage`. Android-резервное
копирование данных приложения отключено (`android:allowBackup="false"`).
Обычная игра не отправляет прогресс на сервер и не синхронизирует его с облаком.

Мы не собираем:

- имя, почту, телефон
- геолокацию
- рекламные идентификаторы
- аналитику поведения
- облачные сохранения

Опциональный «рот» в сигиле — это **явно заданный пользователем webhook URL**.
Если поле пустое, сеть игрой не используется для этого механизма.
Если пользователь указал URL, Игра делает `POST` на этот адрес с короткой фразой,
языком (`ru`) и идентификатором игры (`igra`). Прогресс, идентификатор устройства
и ДНК в этот запрос не включаются. Доступ к webhook полностью определяется
самим пользователем и владельцем указанного URL.

В Android для приложения отключён cleartext-трафик (`usesCleartextTraffic="false"`),
поэтому HTTP webhook не разрешён платформой; HTTPS остаётся допустимым при
явном указании URL. В браузере проверка URL в текущем клиенте требует адрес,
начинающийся с `http`, поэтому фактическая доступность HTTP также зависит от
политики браузера и контекста страницы.

Вибрация и хранение экрана — только для игры.

Удаление приложения или жест «забыть меня» стирает берег.

Контакт владельца репозитория: профиль GitHub JoTalbot.
