# Политика конфиденциальности — ИГРА

ИГРА хранит прогресс **только на устройстве** (localStorage / WebView DOM storage).

Мы не собираем:

- имя, почту, телефон
- геолокацию
- рекладные идентификаторы
- аналитику поведения
- облачные сохранения (если ты сам не вставил webhook)

Опциональный «рот» в сигиле — это твой собственный адрес.  
Если поле пустое, сеть не используется.  
Если ты вставил URL, Игра может отправить туда короткую фразу без сохранения, без идентификатора устройства, без ДНК.

Вибрация и хранение экрана — только для игры.

Удаление приложения или жест «забыть меня» стирает берег.

Контакт владельца репозитория: профиль GitHub JoTalbot.
