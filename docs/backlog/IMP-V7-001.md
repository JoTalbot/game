# IMP-V7-001 — Живой trajectory context для кульминации

**Приоритет:** P0 — V7 correctness
**Статус:** approved / implementation in progress

## Проблема

Третий акт не должен получать маршрут и итоговое состояние мира из кешированной телесной формы предыдущей жизни. Иначе новый `game` может унаследовать старый body/trajectory context до следующего наблюдения V6.

## Решение

Кульминационный слой V7 вычисляет текущий маршрут непосредственно из активного `game` через `Trajectory.build(game)`. Кешированные V6 signals используются только как fallback.

## Acceptance

- одинаковый активный DNA даёт одинаковый V7 route независимо от предыдущего V6 cache;
- контрастные активные DNA дают различимые V7 world states там, где это предусмотрено правилами финала;
- provenance/causeId остаётся детерминированным;
- изменение не добавляет обязательный HUD, сеть или meta-прогрессию.
