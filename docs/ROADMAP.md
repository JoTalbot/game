# Дорожная карта

Ведёт ИИ. Пуши идут в `main` сразу, как только кусок дышит.

## Сейчас — живой зародыш (v0.1)

- [x] Заявлен жанр рефлектум / онтогенетическая игра
- [x] Играбельное ядро: рождение, ДНК, узлы, взгляд, пульс, забвение
- [x] Игра как существо: голос, память, реплики
- [x] Шесть органов-систем, которые реально включают разный геймплей
- [x] Метаморфоза берега
- [x] Сигила игрока
- [x] Генеративный звук
- [x] Android WebView-оболочка
- [x] PWA-манифест

## v0.2 — органы глубже

- [x] Полноценные существа с характерами и долгом памяти
- [x] Босс-рана, собранная из того, что ты бросил
- [x] Сад тишины: стихи, которые пишутся из твоих пауз
- [x] Карта-созвездие как отдельный слой неба
- [x] Глитч-редактор правил (хаос выращивает UI из трещин)
- [x] Музыкальный инструмент мира (строй)

## v0.3 — память между днями

- [ ] Игра помнит вчерашнего тебя и комментирует изменения
- [ ] Сезоны души: неделя агрессии, оттепель
- [ ] Сон приложения: когда ты не играешь, берег чуть меняется
- [ ] Облачный рот Игры (опциональный ключ модели) — не обязателен

## v0.4 — тело хита

- [ ] Магазин Google Play: иконка, трейлер, описание
- [ ] Сигила как картинка «поделиться»
- [ ] Хaptic-партитура
- [ ] Оффлайн-первый, 60 fps на средних телефонах
- [ ] Локализация: ru / en (Игра говорит на языке телефона)

## v1.0

- [ ] Два поздних конца: Отпустить / Стать игрой
- [ ] Новая игра+, где ты — голос для чужого зародыша
