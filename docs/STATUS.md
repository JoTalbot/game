# Статус — 14 августа 2026

## Текущая версия: v0.4.31

Сага экрана закрыта. Oukitel G1 требует два условия разом: софтовое окно приложения (вшито в манифест) и системный тумблер «Для разработчиков → Отключить аппаратные оверлеи». Тогда берег занимает весь экран, касания точные. Телеметрия спит (просыпается по `?debug`).

Ссылка на сборку:
https://github.com/JoTalbot/game/releases/download/v0.4.31/igra-0.4.31.apk

## Что сделать человеку

1. Удалить старую, поставить **0.4.31**, открыть.
2. Скрин чистого полноэкранного берега — для архива.
3. Играть сессию и принести три вещи: как Игра тебя назвала, что выросло первым, в какой момент захотелось закрыть.
