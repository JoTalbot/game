# Статус — 14 августа 2026

## Текущая версия: v0.4.25

В оболочку вшит зонд краски: синтетическое касание в угол окна. Если слой врёт (рисует CSS px один в один в физические, как Oukitel G1) — View растягивается матрицей до полного экрана, касания остаются точными. Здоровые телефоны зонд пропускает без следа. Подпись APK новая: **без удаления старой не встанет**.

Ссылка на сборку:
https://github.com/JoTalbot/game/releases/download/v0.4.25/igra-0.4.25.apk

## Что сделать человеку

1. Удалить старую версию с телефона.
2. Поставить **0.4.25** по ссылке выше.
3. Открыть и подождать три секунды — зонд сам решит.
   - Берег на весь экран + строка `fix=view-matrix` → сделай один скрин (телеметрию сотру) и играй сессию.
   - Снова не весь / новая странность → пришли скрин, телеметрия покажет ответ зонда.
4. Отчёт: имя, первый орган, момент выхода.
