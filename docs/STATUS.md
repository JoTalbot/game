## Что сделать человеку

1. Удалить старую, поставить **0.4.32**, открыть.
2. Скрин + короткое видео (открой → родись → подвигай семя → подожди) — обязательно видео.
3. Проверь состояние: Настройки → Для разработчиков → «Отключить аппаратные оверлеи» — напиши, включён ли.
