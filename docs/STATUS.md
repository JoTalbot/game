# Статус — 14 августа 2026

## Текущая версия: v0.4.24

Встроен страж сломанной плотности: если WebView рисует CSS px один в один в физические (Oukitel G1), движок сам растягивает берег на весь физический экран. Debug-строка слева сверху — телеметрия: один скрин несёт всю карту экрана. Подпись APK новая: **без удаления старой не встанет**.

Ссылка на сборку:
https://github.com/JoTalbot/game/releases/download/v0.4.24/igra-0.4.24.apk

## Что сделать человеку

1. Удалить старую версию с телефона.
2. Поставить **0.4.24** по ссылке выше.
3. Открыть. Берег должен быть на весь экран; debug-строка покажет `phys`.
   - Если так — пришли один скрин (телеметрию сотру) и играй сессию.
   - Если берег снова не весь — пришли скрин сразу: четыре строки телеметрии скажут, кто врёт.
4. Отчёт: имя, первый орган, момент выхода.
