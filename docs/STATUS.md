## Стенд проверок

Браузера в песочнице нет, поэтому проверки живут в репозитории:

```
node tools/probe/run.js
```

**77 проверок, 0 падений** (около четырнадцати секунд). Стенд умеет смотреть на узел настоящим жестом (взгляд 1.35 с → кристаллизация), поднимает настоящий `engine.js`, держит палец на узле, слушает звук подставным Web Audio, считает речь, крутит час игры и меряет цену кадра. Он уже поймал недостачи, которые иначе уехали бы в APK: рендер падал без настоящего игрока, `applyLaw` падал без UI, Director спотыкался без ввода, сейв пух до 126 КБ, метаморфоза стирала сад целиком, забота вредила, звуковой граф тёк, а слабому телефону не доставалось обещанного послабления.

Правило смены: **каждая проверка испытывается подлогом.** Сломай то, что она стережёт, — она обязана покраснеть; почини — позеленеть. Проверка, не поймавшая подлог, ничего не проверяет. И у экономии всегда две крайности: не сэкономить и сэкономить всё — сторож стоит с обеих сторон. Добавляешь орган — добавляй проверку.

Рядом два постоянных замера баланса — гонять после любой правки прилива, забвения или заботы:

```
node tools/probe/balance.js   # сколько человек вырастил и сколько у него забрали
node tools/probe/care.js      # окупается ли возвращение к узлу
```
