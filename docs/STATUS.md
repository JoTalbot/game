## Что сделать человеку

1. Удалить старую версию с телефона.
2. Поставить **0.4.23** по ссылке выше.
3. Открыть — берег должен быть на весь экран (в debug-строке слева сверху: `384×853 dpr1.50` = здоровье; `576×1280` = боль, пиши сразу).
4. Пройти сессию и написать три вещи (имя, первый орган, момент выхода).
