# Статус — 14 августа 2026

## Текущая версия: v0.4.7

Убраны любые несовместимые вызовы API (WindowInsets/WindowInsetsController), защищены все точки входа в MainActivity, экран работает на всех версиях Android.

Ссылка на сборку:
https://github.com/JoTalbot/game/releases/download/v0.4.6/igra-0.4.6.apk

В следующем APK исправляется масштаб WebView: отключён overview-режим и начальный масштаб привязан к плотности экрана. Сборка требует восстановить локальный `aapt2` из Android SDK.

## Что сделать человеку

1. Удалить старую версию с телефона.
2. Поставить **0.4.6** по ссылке выше.
3. Открыть — игра запускается сразу, берег на весь экран.
4. Пройти сессию и написать три вещи (имя, первый орган, момент выхода).
