# IMP-V11-001 — first-session UX

Дата: 2026-09-14
Статус: IMPLEMENTED / deterministic probe added
Приоритет: P0

## Цель

Новый игрок должен понять базовый жест через саму игру, без отдельного tutorial-screen, popup, XP, streak или другой retention-механики.

## Реализация

Добавлен `web/js/v11-first-session.js`.

После осознанного рождения слой ведёт короткую одноразовую сессию подсказок:

1. `birth` — «коснись. задержись. или просто стой.»
2. первое действие — «теперь найди точку и задержи взгляд.»
3. первый захват взгляда — «не отпускай. взгляд сам сделает остальное.»
4. успешный первый жест — «ты не нашёл это. ты это вырастил.»

Есть RU/EN варианты. Состояние не пишется в save и не меняет игровые правила, баланс или world state.

Слой наблюдает существующий lifecycle `startBirth → onDown → onUp`, поэтому обучение не создаёт второй обработчик жеста и не вмешивается в touch semantics.

## Проверка

`tools/probe/v11-first-session.js` проверяет:

- стабильный API слоя;
- установку lifecycle hooks;
- переход birth → touch → gaze → done;
- наличие явной русской стартовой подсказки.

Следующий обязательный этап для Android UX — физическая проверка на weak-device профиле. Автоматический gate не заменяет реальную руку на стекле, потому что человечество пока не придумало unit-test для пальца.
