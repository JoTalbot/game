# ИГРА — большой план развития до готовности

> Дата плана: 2026-09-03.
> База: v2.33 + V3-020..030 + IMP-V3-031..035. V3-030 — первый полноценный акт, но не финальная коммерческая игра.
>
> Главный принцип: не превращать ИГРУ в обычную RPG с меню, XP, классами, квест-журналом и FOMO. Смысл должен продолжать расти из поведения игрока: **действие → след → память → изменённый мир → новое поведение → новая история**.

## 0. Финальное определение готовности

ИГРА считается готовой к публичному релизу, когда одновременно выполнены все ворота:

- **Продукт:** минимум 3 содержательных акта, с сильной общей аркой и несколькими жизненными циклами.
- **Реиграбельность:** минимум 3 качественно различающиеся траектории и разные последствия финалов.
- **Мир:** места, существа, органы, законы и Director образуют связанную причинную систему.
- **Продолжение:** первый/второй финал меняет последующее прохождение, а не закрывает приложение.
- **Контент:** достаточно событий и вариаций, чтобы игрок не увидел повторяемый скелет за одну-две сессии.
- **UX:** игра объясняет себя через мир, звук, жесты и последствия; технические системы не торчат наружу.
- **Persistence:** сейв переживает перезапуск, обновление APK и длительную историю; размер ограничен и контролируем.
- **Android:** стабильный APK, WebView, touch, back/resume, ротация/жизненный цикл, слабые устройства, отсутствие потери сейва.
- **Offline:** основной игровой цикл полностью работает без сети.
- **Performance:** устойчивый FPS на целевых слабых Android-устройствах, без роста памяти от длительной сессии.
- **Accessibility:** читаемость, размер текста, haptic/audio fallback, отсутствие обязательного звука или цвета для понимания.
- **Localization:** ru/en полностью покрыты и не ломают layout.
- **Release:** versioning, stable signing, privacy/store materials, screenshots/trailer, crash-free release candidate.
- **QA:** автоматические probes + реальные длинные ручные прогоны + чистая установка/обновление поверх существующего сейва.
- **Monetization:** если появится, не должна быть обязательной для понимания/продолжения игры; базовая версия не зависит от неё.

# PHASE 4 — V3.1: второй слой жизни

### Цель
Превратить первый акт из единственного длинного опыта в устойчивую систему, способную поддерживать несколько актов.

### Работы
- V4-001: унифицированная модель причинного события и компактного provenance.
- V4-002: контентные archetype-пулы Director без копирования логики.
- V4-003: второй акт с собственным конфликтом, а не просто большим количеством узлов.
- V4-004: 8–12 новых событий, каждое связано минимум с двумя существующими сигналами.
- V4-005: 3 новых повторяющихся персонажа/существа с памятью.
- V4-006: 3 новых места с собственной историей.
- V4-007: последствия второго акта для органов, отношений и экологии.
- V4-008: контрастные маршруты «сохранять / отпускать» и «сближаться / избегать».

### Gate
- 60–120 минут суммарной естественной игры без ощущения повторения первого акта.
- Минимум две причинно разные концовки второго акта.
- CI проверяет минимум три сценария.

### Цель

- V5-004: цепочки событий 3–5 звеньев с альтернативными ветвями.
- V5-005: новые законы мира, возникающие из накопленной экологии.
- V5-006: сезонные/возрастные изменения без календарного FOMO.
- V5-007: редкие «личные» события уровня всей жизни.
- V5-008: защита от повторяемости и event spam.

### Gate
- 3 контрастных поведения дают разные world-state.
- Один и тот же берег после нескольких жизней заметно меняется.
- События имеют понятные причины, но не требуют журнала.

# Порядок работы

1. Сначала фиксируем этот план в репозитории.
2. Каждый новый продуктовый improvement сначала получает `IMP-*` в backlog.
3. Затем реализация батчем.
4. После каждого значимого батча: probes → CI → анализ результата.
5. Тестовый фикс, не меняющий продукт, можно делать без нового IMP.
6. Не плодим версии ради счётчика.
7. Не добавляем обязательные daily/streak/FOMO, квест-журнал, карту, классы, XP или донат-экономику только ради удержания.
8. Если план сталкивается с фактическим поведением игры, код и реальные тесты важнее красивого документа: план обновляется, а не реальность подгоняется под него.

# Метрики готовности

- playable acts: **3+**
- качественно разные жизненные траектории: **3+**
- финальные состояния: **3+**
- запоминающиеся места: **8+**
- повторяющиеся ключевые существа: **6+**
- причинно связанные длинные цепочки: **5+**
- редкие персональные события: **10+**
- обязательная сеть: **нет**
- обязательная монетизация: **нет**
- FOMO/streak/daily reward: **нет**
- незакрытые critical/blocker перед релизом: **0**
