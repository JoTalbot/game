# ИГРА — backlog V4 / путь от первого акта к готовности

> Этот backlog является рабочим продолжением `docs/ROADMAP_TO_READY.md`.
> V3-030 закрыт как первый полноценный акт. Здесь фиксируются следующие продуктовые работы до Release Candidate.
>
> Правило: любое новое улучшение сначала получает `IMP-*`, затем реализуется и проверяется. Тестовые исправления без изменения продукта могут идти напрямую.

**P0**
**Статус:** реализовано

## Batch registration / новые улучшения

### IMP-RC-001. Unified release systems layer
**P0**
**Статус:** выполняется

Единый bounded state layer связывает причинность, Director budget, второй/третий акт, места, повторяющихся существ, экологию, законы, тело/идентичность, replay и release-readiness без обязательного meta UI.

### IMP-RC-002. Deterministic control scenarios
**P0**
**Статус:** выполняется

Контрольные сценарии фиксируют seed, действия, причинные цепочки, два контрастных маршрута, финал и следующую жизнь. Это делает регрессию воспроизводимой.

### IMP-RC-003. Save budget + migration envelope
**P0**
**Статус:** выполняется

Новый state имеет версию, bounded history, компрессию старых следов и безопасное восстановление из старого/частично повреждённого состояния.

### IMP-RC-004. RC gate probe
**P0**
**Статус:** выполняется

Один probe проверяет количественные Definition of Done, offline shell, schema/migration, idempotence, replay, контрастные пути, post-finale continuation и отсутствие FOMO/монетизационного ядра.

### IMP-RC-005. Canonical trajectory bridge
**P1**
**Статус:** реализовано

Release layer использует канонический результат `Trajectory.profile()` (`path`, `dominant`, `secondary`) вместо проверки поля `kind`, которого в profile нет. Контрастные жизненные траектории формируются из реального поведения игрока.

### IMP-RC-006. Canonical life behavior bridge
**P1**
**Статус:** реализовано

Release layer читает реальные поля `Life.behavior` (`born`, `returns`, `pulses`, `still`, `motion`) и не зависит от несуществующих `care`/`harm`. Поведенческий вклад влияет на выбор траектории и причинные следы.

### IMP-RC-007. RC version identity
**P0**
**Статус:** реализовано

Release Candidate имеет собственную идентичность версии и versionCode, согласованные между JS, APK build script, Gradle и release-документацией. Базовую v2.33 нельзя выдавать за RC v3.

### IMP-RC-008. Real trajectory control scenarios
**P0**
**Статус:** реализовано

RC gate больше не подставляет три готовых счётчика траекторий. Три воспроизводимых контрольных сценария формируют разные `Trajectory.profile().path` из реальных DNA и `Life.behavior`, после чего эти канонические пути реально записываются ReleaseSystems. Это проверяет связку «поведение → траектория → release state» и снижает риск ложнозелёного RC gate.

## Definition of Done

- 3+ содержательных акта.
- 3+ качественно разные жизненные траектории.
- 3+ различных финальных world-state.
- 8+ исторических мест.
- 6+ повторяющихся ключевых существ.
- 5+ длинных причинных цепочек.
- 10+ редких персональных событий.
- Полный offline core loop.
- Стабильный Android APK и сохранение.
- Migration со старых поддерживаемых save.
- Полный CI зелёный на Release Candidate.
- 0 critical/blocker.
- Нет обязательных FOMO/streak/daily reward/ads/network/монетизации.
