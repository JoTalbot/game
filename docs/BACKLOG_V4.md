# ИГРА — backlog V4 / путь от первого акта к готовности

> Этот backlog является рабочим продолжением `docs/ROADMAP_TO_READY.md`.
> V3-030 закрыт как первый полноценный акт. Здесь фиксируются следующие продуктовые работы до Release Candidate.
>
> Правило: любое новое улучшение сначала получает `IMP-*`, затем реализуется и проверяется. Тестовые исправления без изменения продукта могут идти напрямую.

## PHASE 4 — V3.1: второй слой жизни

### V4-001. Унифицированный контур причинности
**P0 — фундамент**
**Статус:** проверить существующую реализацию и закрыть интеграционные пробелы.

Действие → событие → след → место/отношение/орган → экология → Director → будущее событие должны использовать совместимые идентификаторы причин.

### V4-002. Контентные archetype-пулы Director
**P0**
**Статус:** запланировано

Director получает расширяемые пулы событий по контекстам, причинам и фазам. Контент не дублирует runtime-логику и может безопасно расширяться.

### V4-003. Второй акт
**P0**
**Статус:** запланировано

Новый акт должен иметь собственный конфликт и последствия, а не быть набором дополнительных узлов.

### V4-004. Контент второго акта
**P0**
**Статус:** запланировано

Добавить 8–12 событий, связанные минимум с двумя существующими сигналами и имеющие физические последствия.

### V4-005. Повторяющиеся существа второго акта
**P1**
**Статус:** запланировано

Минимум три субъекта с памятью, узнаваемым поведением и изменениями после взаимодействий.

### V4-006. Исторические места второго акта
**P1**
**Статус:** запланировано

Минимум три места, которые меняются от возвращений и связывают несколько событий/жизней.

### V4-007. Последствия второго акта
**P1**
**Статус:** запланировано

Результаты акта должны менять минимум два слоя: органы, отношения, места, экологию или законы.

### V4-008. Контрастные маршруты
**P1**
**Статус:** запланировано

Сохранение/отпускание и сближение/избегание должны давать различимые состояния без выбора класса.

## Definition of Done

- 3+ содержательных акта.
- 3+ качественно разные жизненные траектории.
- 3+ различных финальных world-state.
- 8+ исторических мест.
- 6+ повторяющихся ключевых существ.
- 5+ длинных причинных цепочек.
- 10+ редких персональных событий.
- Полный offline core loop.
- Стабильный Android APK и сохранение.
- Migration со старых поддерживаемых save.
- Полный CI зелёный на Release Candidate.
- 0 critical/blocker.
- Нет обязательных FOMO/streak/daily reward/ads/network/монетизации.
