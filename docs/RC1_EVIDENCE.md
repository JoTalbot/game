## Combined выводы

### 🟢 Здорово

- `59 fps` сохраняется на слабом профиле при 14-минутной сессии.
- Save остаётся живым.
- Основной цикл реально используется: `314` касаний → `253` взгляда → `188` выращено.
- Мир и возвраты используются существенно глубже первой сессии: `17` возвращений, `19` якорей, `7` берегов, `7` дорог, `6` существ, `10` законов.
- Второй прогон достиг `become`, поэтому финальный путь физически пройден в baseline-сборке.

### 🟡 Touch → принято к реализации

Две независимые физические сессии подтверждают пограничную зону:

- session 1: `3` finger-left, медиана `128 px`, максимум `139 px`;
- session 2: `5` finger-left, медиана `132 px`, максимум `174 px`;
- суммарно `8` finger-left событий;
- действующий порог `126 px`.

При этом во второй сессии `20/27` срывов были явным отпусканием. Поэтому глобально поднимать порог до `140 px` нельзя: это смешало бы намеренный release и accidental slip.

Решение: реализовать hysteresis/grace zone `126–140 px`, с сохранением удержания при возврате внутрь и отменой при устойчивом выходе `>140 px`. `touchend` и `touchcancel` остаются отдельными исходами.

### 🟡 Color → наблюдение

Первая сессия дала `0` цветов, вторая `2`. Этого всё ещё недостаточно для изменения UX. Tutorial ради одной метрики не вводить.
