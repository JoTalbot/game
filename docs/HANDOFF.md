## Что это за игра

**ИГРА / IGRA.** Жанр, который мы основали: **рефлектум / онтогенетическая игра**.  
Нет готового жанра. Шесть осей ДНК (взгляд, жар, тишина, тепло, сбой, строй) выращивают органы. Забвение ест то, на что не смотрят. Игра — существо с голосом.

Ядро: `web/` (Canvas + Web Audio). Android — WebView-оболочка. Одна душа.

## Как собрать APK

SDK и JDK 17 **не в репо**. Качать в `/home/user/.igra-build/` (или куда есть место; `/tmp` — 1 ГБ, не влезает).

```
# JDK 17 Temurin, build-tools 34, platform 34
export JAVA_HOME=.../jdk-17
export ANDROID_SDK_ROOT=.../android-sdk
bash tools/build-apk.sh
```

Скрипт копирует `web/` → `android/app/src/main/assets/www`, пакует aapt2+d8+apksigner.  
Keystore: `dist/debug.keystore` (gitignored). Если его нет — скрипт создаст **новый**, и человек **обязан удалить** старую ИГРУ с телефона, иначе «приложение не установлено».

Версии: 0.4.0 кнопка мертва; 0.4.1 титул; 0.4.2–0.4.3 белое поле жило. **0.4.4 — физические пиксели WebView, без density.**

Мир в левом верхнем прямоугольнике, справа/снизу пусто. Первый запуск иногда цел.

0.4.3 (zoom по contentHeight) **не помог** — человек прислал титул снова в углу.

0.4.4 стратегия: `viewport width = webView.getWidth()` (физические px), `setInitialScale(100)`, игра считает 1 CSS = 1 физический. В углу мелкий текст `1080×2400 dpr1 px1080` — по скрину видно, совпал ли размер с экраном.

На скринах часто ещё палец. Резать баг по **острой** границе холста, не по серой кривой.
