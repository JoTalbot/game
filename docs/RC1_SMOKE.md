# RC1 — физический Android smoke gate

> Контракт: `v3.0.0-rc1` / versionCode `600`.
> Автоматический RC gate зелёный. Этот документ закрывает только то, что нельзя достоверно подтвердить CI.

## Правило выпуска

Не создавать production release и не считать игру production-ready, пока физический smoke не подтверждён на реальном Android.

После успешного smoke:

1. создать immutable tag/release `v3.0.0-rc1`;
2. собрать APK с release signing;
3. проверить SHA-256;
4. провести ограниченное RC-тестирование;
5. отдельно принять решение о production Play release.

## Real-player evidence — 2.33 baseline

Получен реальный игровой паспорт, 5.7 мин, экран `427×948 @1.0 (слабый)`:

- плавность: `59 fps`, тяжёлых кадров `100`;
- касаний: `141`; взглядов `102`; выращено `85`; срывов `10`; шагов `19`; пустота `4`; пульсов `11`;
- причины срывов: палец ушёл `×3`, система забрала жест `×1`, отпустил сам `×6`;
- медиана срыва `0.5 с`; палец уезжал медиана `128 px`, максимум `139 px`, текущий порог `126 px`;
- срыв сразу после зова: `2` в первые `20 с`;
- сила: взгляд `1059`, раны `0`, пульсы `80`, босс `87`, минимум `66`;
- камера: `0.43–1.06`, среднее `1.00`;
- за жизнь: `85` выращено, `10` живых;
- возвращений `4`, якорей `7`, сейчас `3/3`, спасено `0`;
- прилив `18`, метаморфоза `57`;
- за всю жизнь: `2` берега, `2` дороги, `2` существа;
- затронуто `2` закона, `5` пульсов, `0` цветов;
- небо `1`, сигила `2`;
- природа: `Тот, кто не повторяется · сбой`;
- сезон: `сбой`, день `1`, сессия `1`;
- ключевой UX-сигнал: «возвращаться было зачем?» → `да, видно`.

### Интерпретация baseline

- `59 fps` на слабом профиле и `11` пульсов подтверждают хороший performance/touch baseline.
- `1/10` срывов из-за того, что система забрала жест, указывает, что прежний WebView touch-шов существенно ослаблен.
- `3/10` срывов из-за ухода пальца происходят практически у границы: медиана `128 px` при пороге `126 px`. Это кандидат на RC improvement, но не доказанный blocker.
- `6/10` срывов — сознательное отпускание; не считать их автоматически ошибкой.
- `0` цветов за сессию не доказывает discoverability-проблему. Нужны независимые сессии, чтобы отличить отсутствие интереса от непонятности механики.
- «Возвращаться было зачем? → да, видно» — положительный qualitative replay signal и полезный baseline для RC.

## RC improvement backlog

### IMP-RC1-TOUCH — grace zone для физического порога срыва

**Статус: предложено к следующей итерации, не blocker.**

Наблюдение: медиана ухода пальца `128 px` при пороге `126 px`, максимум `139 px`. Предлагается исследовать гистерезисную зону, например `126–140 px`, с сохранением настоящего срыва за верхней границей. Не повышать порог вслепую: сначала проверить несколько независимых реальных сессий и убедиться, что gesture feel не становится «резиновым».

### IMP-RC1-COLOR — проверка discoverability цвета

**Статус: наблюдение, не blocker.**

Одна сессия дала `0` затронутых цветов. Не добавлять подсказки или туториал автоматически. Сначала собрать несколько независимых паспортов и сравнить поведение.

## Evidence

Зафиксировать минимум:

- модель и Android;
- APK SHA-256;
- дату и время smoke;
- результат каждого пункта;
- скрин/видео при найденном дефекте;
- crash/ANR log при найденном дефекте.

Любой critical/blocker возвращает RC в разработку. Не маскировать проблему зелёным CI: CI не держит телефон в руке, потому что у CI, к счастью, нет рук.

## Exit criteria

RC1 physical gate закрыт, если:

- clean install и первый boot успешны;
- save/restart и process-death recovery успешны;
- upgrade path проверен или документирован как физически недоступный для текущего прогона;
- offline smoke успешен;
- финальные release/become сценарии работают;
- critical/blocker отсутствуют;
- SHA-256 и release metadata совпадают с build contract.
