# V3-020..030 — batch status

Дата: 2026-09-03

## Реализовано

- **V3-020** — незавершённая нить и физическое продолжение возвращения через существующий DirectorEvents.
- **V3-021** — редкие персональные моменты из нескольких накопленных сигналов, без коллекционной UI-меты.
- **V3-022** — жизнь после финала, сохранение истории между циклами.
- **V3-023** — перенос отношения через жизнь/смену кожи: распознавание, направление связи, bounded history.
- **V3-024** — места с собственной историей, нормализованная пространственная идентичность и связь нескольких жизней.
- **V3-025** — накопительная экология: один след читается Director/органами и физическими сущностями/узлами.
- **V3-026** — причинные следы пяти фаз первого акта с bounded history и привязкой к предыдущему состоянию.
- **V3-027** — разные жизненные пути через фактическую траекторию, ДНК, поведение и память.
- **V3-028** — ограниченная память с преобразованием старых редких следов в производные `scar`-формы.
- **V3-029** — разные стартовые физические следы `release` / `become` следующей жизни.
- **V3-030** — интеграционный слой `v3-continuity.js`, связывающий V3-020..029 без отдельного meta-progression UI.

## Проверка

- Добавлен `tools/probe/v3-continuity.js`.
- CI workflow `life.yml` запускает и существующий deep probe, и интеграционный probe.
- `IMP-V3-030-01` отдельно зафиксирован и реализован: тесты используют реальное persistence-state и сбрасывают связанные caches.
- Push-triggered GitHub Actions run должен быть проверен по фактическому результату. Пока доступный GitHub connector не предоставляет этот push-run через текущий wrapper, поэтому статус CI не объявляется зелёным без доказательства.

## Продуктовый смысл

V3-020..030 не добавляют ежедневные награды, streak, рекламу, обязательную сеть или монетизационную петлю. Цель батча — заменить ощущение расширенного vertical slice на причинную непрерывность: игрок действует → берег меняется → память сохраняется → следующая жизнь стартует иначе → старые отношения и места отвечают.
