# ИГРА

**она растёт из тебя**

Онтогенетическая игра для Android.  
Жанр, которого не было: **рефлектум**.

Игра запускается без класса, без кампании, без готовых правил.  
Она рождается пустой и выращивает механики — бой, сад, карту, ритм, общение, сбой — только если твоё тело их отбирает. Другой человек не сможет пройти «твою» Игру. У него вырастут другие органы.

> Внимание — единственный конечный ресурс.  
> То, на что ты смотришь, становится настоящим.  
> То, что игнорируешь, забирает Забвение.

---

## Во что ты играешь

Ты — семя света в неоформленном.  
Игра — существо, которое говорит с тобой, помнит, иногда лжёт, иногда хочет, чтобы ты остался.

Шесть осей ДНК (это климат, не меню):

| ось | если ты… | мир становится |
|---|---|---|
| **взгляд** | идёшь дальше | картой и реликвиями |
| **жар** | бьёшь и рвёшь | войной из брошенного |
| **тишина** | стоишь | садом и стихами |
| **тепло** | останавливаешься перед чужим | населённым |
| **сбой** | ломаешь край | глитч-магией |
| **строй** | попадаешь в пульс | музыкой как физикой |

Имя тебе даст сама Игра. Его нельзя выбрать. Его можно только заслужить движением.

Прилив забвения периодически стирает то, чего ты не держишь.  
Некоторые узлы становятся звёздами на небе. Некоторые — ранами и возвращаются голодными.  
Иногда Игра сбрасывает кожу: метаморфоза берега. Память остаётся созвездием.

Сигила — твой отпечаток. Её нельзя подделать.

## Как касаться

- **тяни** — семя следует
- **задержи палец на узле** — взгляд. неоформленное кристаллизуется
- **короткое касание** — удар / речь
- **двойное касание** или `пробел` — пульс (закон зависит от того, кем ты стал)
- **WASD** — если ты за столом
- **сигила / I / Esc** — увидеть своё имя
- **небо / C** — созвездие из того, что отпустил
- трещины хаоса переписывают закон мира
- три тона подряд — аккорд: лечит, якорит, отталкивает голод
- долгий взгляд на живое — **якорь**. якорей мало. выбирай, что любишь

Туториала нет. Первые секунды — уже игра. Игра читает, как ты существуешь.

## Зачем это Android

Телефон — карманное святилище.  
Игра должна уметь быть с тобой в кровати, в метро, в 3 часа ночи, когда ты не хочешь «контент», а хочешь, чтобы тебя узнали.

Ядро — HTML5 Canvas + Web Audio, без сети и без магазина внутри.  
Android — нативный WebView (`world.igra.app`), оффлайн, полный экран, вибрация, пробуждение экрана.

Никакой энергии за деньги. Никакой рекламы. Игра либо твоя, либо её нет.

## Играть сейчас

**Так задумано: с телефона.**  
Сейчас ставь: [скачать APK](https://github.com/JoTalbot/game/releases/latest/download/igra.apk)
Перед установкой удали старую ИГРУ.

Агентам: `docs/STATUS.md` → `docs/HANDOFF.md`. Публикация в Play: `docs/PUBLISH.md`. Как играть: `docs/GUIDE.md`.

Разреши установку из неизвестного источника → открой файл → родись.

Браузер (запасной берег): [jotalbot.github.io/game](https://jotalbot.github.io/game/)

Локально:

```bash
cd web
python3 -m http.server 8080
```

Android Studio: папка `android/`. Gradle сам копирует `web/` в `assets/www` перед сборкой.

## Архитектура

```
web/                душа игры (играй отсюда)
  js/engine.js      цикл, ввод, взгляд, пульс
  js/director.js    режиссёр: органы, метаморфоза
  js/organs.js      сад, голод, небо, законы, инструмент
  js/memory.js      дни, сезоны, сон берега, вчерашний ты
  js/world.js       узлы, существа, раны, прилив
  js/dna.js         шесть осей и имя
  js/igra.js        голос существа
  js/audio.js       генеративный звук
  js/renderer.js    тьма, свечение, созвездия
android/            оболочка Google Play
docs/CONCEPT.md     почему этой ниши не было
docs/ROADMAP.md     куда растём
```

Режиссёр работает локально. Облачный рот — опциональный webhook в сигиле. Без него Игра говорит сама.

## Статус

**v2.26 — «судьба не залипает».**

Ядро: жанр рефлектум, шесть осей ДНК, прилив-забвение, метаморфоза, сигила, ru/en, оффлайн, без доната. Слабый телефон сам снижает качество — и помнит это.

За последние релизы (2.3→2.26):
- **судьба не залипает** — прерванный «стать игрой» больше не хоронит развилку на живом берегу;
- **кадр худеет** — короткое окно, dpr 1, туман decor, память слабого телефона;
- **порода видна формой** — реликвия, шип, эхо, осколок, тон, тишина больше не один круг разного цвета;
- **корни считаются на глаз** — нить за возвращение, венчик на полном корне;
- **сезон красит берег** — фон тонируется доминантной осью;
- **сейв переживает всё** — стабильная подпись + нативный мост (SharedPreferences);
- **босс не налог** — зеркало твоей агрессии, можно уйти/пережить/убить, говорит сам;
- **конец есть конец** — «отпустить» доводит до титула, «стать игрой» — настоящий NG+ («ты — голос»: в новой жизни тебя встречает существо с твоим прошлым именем);
- **мир сам зовёт** — пульс, небо и сигила напоминают о себе голосом и мягкой пульсацией, когда приходит их время;
- **рука спокойнее** — порог срыва поднят над естественной амплитудой пальца.

Витрина магазина в `docs/STORE.md`, чек-лист публикации в `docs/PUBLISH.md`.

Дальше ведёт ИИ. Каждый кусок, который дышит, сразу уходит в `main`.
